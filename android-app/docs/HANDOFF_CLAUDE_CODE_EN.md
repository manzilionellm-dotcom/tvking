## BACKEND (Cloudflare worker, app.7themotion.com)
Public routes the app uses:
- POST /api/heartbeat {mac, model, platform:'tv', sources[], recent[]} → status
  (also stores the device's source inventory and watch history by MAC).
- GET /api/status/:mac → subscription status.
- GET /api/device-source/:mac → source(s) pushed by the panel (trio of up to 3).
- GET /api/history/:mac → watch history (multi-box sync).
Admin API (api_v1.js): /api/v1/devices/:id/overview (360° card: license,
presence, M-Trio, real inventory), /api/v1/sources/:mac, activation, etc.
Stable MAC: derived from ANDROID_ID via plugin `packages/tvking_device/`, prefs
take priority (never changes once set).
